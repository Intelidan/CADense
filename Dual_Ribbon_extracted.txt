Because they never touch, SolidCraft's native B-Rep sewing algorithm (sew.rs) can process the geometries without throwing non-manifold topology exceptions.The Major Tradeoff with Parametric ScalingWhile adding a clearance gap allows you to use the native folding tool, it still does not fix the parametric port scaling issue.If the user changes a port width from 100 mm to 200 mm, a native 3D fold feature that was executed before the stretch cannot automatically calculate how to widen the base plate while keeping the folded side walls attached at their correct positions.
